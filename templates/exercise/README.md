# Exercise Template

Replace this file when creating a new exercise branch.

## Goal

Explain in 2-4 lines what the student is expected to learn.

## Task

1. Implement the missing logic in `src/index.js`.
2. Make all tests pass.

## Constraints

- keep the solution simple and deterministic
- avoid `var` unless it is part of the lesson

## Run locally

```bash
npm install
npm run check
```
