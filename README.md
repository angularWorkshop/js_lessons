# Topic 14.1 - Workflow Scripts Map

## Goal

This exercise models npm scripts as a project workflow contract.
You will preserve existing scripts and add the standard commands for development and checks.

## What you are training

- preserve existing script definitions
- add standard workflow commands
- combine checks into one project-level command

## Task

Finish `src/index.js`.

1. Keep every existing script from `baseScripts`.
2. Add `dev`, `test`, `build`, and `check`.
3. Make `check` run test and build together.

## Run locally

```bash
npm install
npm run test
```
