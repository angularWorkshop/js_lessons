# Topic 2.1 - Basic Types State

## Goal

This starter branch helps you see the main JavaScript value types as separate, concrete things.
The task is not to memorize theory words. The task is to place the right kinds of values into one small state object and notice how they differ.

## Task

Finish `src/index.js`.

1. Add the correct string value.
2. Add the correct number value.
3. Add the correct boolean value.
4. Use `null` where a value is explicitly absent.
5. Use `undefined` where the next value is still missing.
6. Keep the final `studentTypeState` object in sync.

## Expected values

- `displayName` should be `Mila`
- `finishedLessons` should be `2`
- `hasMentorAccess` should be `false`
- `mentorNote` should be `null`
- `nextLessonId` should be `undefined`
