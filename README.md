# Topic 1.1 - Repair a Broken First Script

## Goal

This completed solution shows how a tiny script becomes understandable again when every value says exactly what it should say.
The focus is still on reading code from top to bottom and ending with one reliable result object.

The file exports:

- `scriptName`
- `scriptPurpose`
- `currentStep`
- `isFixed`
- `statusLine`
- `repairState`
