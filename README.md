# Topic 1.1 - Repair a Broken First Script

## Goal

This starter branch is about reading a tiny file calmly and bringing it back to a consistent state.
The task is still beginner-level: no hidden tricks, just clean values, strict mode, and one final result object.

## Task

Finish `src/index.js`.

1. Keep `'use strict';` at the top of the file.
2. Replace the placeholder values for the repaired script.
3. Build the final `statusLine`.
4. Complete `repairState` so the whole file tells one coherent story.

## Requirements

- `scriptName` should be `Starter Repair`
- `scriptPurpose` should be `Learn how a small script is organized.`
- `currentStep` should be `2`
- `isFixed` should be `true`
- `statusLine` should be `Starter Repair: step 2 is ready.`
- `repairState.strictMode` should be `true`

## StackBlitz auto-check mode

- StackBlitz starts with `npm run start:dev`
- tests run on startup and after each save
- terminal shows `ASSIGNMENT STATUS: COMPLETED` or `ASSIGNMENT STATUS: NOT COMPLETED`
