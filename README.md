# Topic 1.1 - First Script, Strict Mode, and Predictable Output

## Goal

This completed solution shows the smallest useful JavaScript script we can discuss seriously.
It keeps strict mode at the top, stores a few clear values, and finishes with one predictable object.

## What this exercise teaches

- a script is read from top to bottom
- `'use strict';` belongs at the very start
- constants can store the main values of a tiny program
- one final object helps us see the whole script result in one place

## Final result

The file exports:

- `courseName`
- `studentName`
- `lessonNumber`
- `isReady`
- `introMessage`
- `consoleLine`
- `firstScriptState`
