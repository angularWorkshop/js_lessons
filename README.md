# Topic 2.1 - Basic Types State

## Goal

This completed solution shows the main beginner value types in one small, readable state object.
The idea is simple: strings, numbers, booleans, `null`, and `undefined` all represent different kinds of data, and JavaScript treats them differently on purpose.

## Final result

The file exports:

- `displayName`
- `finishedLessons`
- `hasMentorAccess`
- `mentorNote`
- `nextLessonId`
- `studentTypeState`

## Run locally

```bash
npm install
npm run test
```
