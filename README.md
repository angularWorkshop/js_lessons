# Topic 8.2 - Render Lesson Cards

## Goal

This exercise is the first rendering task in the browser part of the course.
You will turn lesson data into DOM cards and insert them into a container.

## What you are training

- create DOM elements with `document.createElement`
- build one card from one data object
- render a list of cards into a container

## Task

Finish `src/index.js`.

1. In `createLessonCard`, build one lesson card element.
2. In `renderLessonCards`, render all cards into the container.
3. In `buildCardsSnapshot`, return the final DOM summary after rendering.

## Run locally

```bash
npm install
npm run test
```
